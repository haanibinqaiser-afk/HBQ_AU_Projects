# Network Security & Defense Labs

This repository serves as a centralized hub for hands-on projects, labs, and simulations focused on network security, traffic analysis, perimeter defense, and infrastructure security. Each directory represents a dedicated lab environment containing configuration files, packet captures (`.pcapng`), network topologies, and detailed analysis reports.

## 🛠️ Core Technical Stack

- **Traffic Analysis & Sniffing:** Wireshark, tshark
- **Reconnaissance & Scanning:** Nmap, Masscan
- **Packet Manipulation & Scripting:** Scapy
- **Exploitation & MITM Frameworks:** Bettercap, Ettercap
- **Network Simulation & Topology Design:** Cisco Packet Tracer

Welcome to the **Presentations** branch of my portfolio. This repository contains a curated collection of presentations delivered during my undergraduate studies, covering topics across Cybersecurity, Computer Science, and Applied Mathematics.

## 📌 Note on Formats (`.pptx` vs `.pdf`)
Each presentation is provided in two formats:
* **`.pptx` (Recommended):** Download this version to experience the advanced **Morph transitions**, dynamic animations, and precise visual formatting that were built into the original slides with significant effort.
* **`.pdf`:** A static version optimized for quick previewing directly inside GitHub or on devices without Microsoft PowerPoint.

## 📂 Presentation Catalog

### 1. Quantum Cryptography 🔐
* **Core Topics:** Quantum Computing fundamentals (Superposition, Entanglement, Qubits, Interference), Quantum Key Distribution (QKD), BB84 Protocol, Post-Quantum Cryptography (PQC), Shor's and Grover's algorithms, and real-world 5G/telecom applications.
* **Format:** [PPTX](https://github.com/haanibinqaiser-afk/HBQ_AU_Projects/blob/Presentations/Material/(Group%201)%20Quantum%20Cryptography%20PPT.pptx) | [PDF](https://github.com/haanibinqaiser-afk/HBQ_AU_Projects/blob/Presentations/Material/(Group%201)%20Quantum%20Cryptography%20PPT.pdf)
* **Collaborators:** Haani Bin Qaiser, M. Asim Saleem, M. Abaid

### 2. Torrent Poisoning: Antipiracy & Anonymity 🌐
* **Core Topics:** Peer-to-Peer (P2P) network models, the mechanics of the BitTorrent protocol, methods of torrent poisoning used for copyright enforcement, and user privacy/anonymity mechanisms (VPNs, Proxy Servers, and the Tor Network).
* **Format:** [PPTX](https://github.com/haanibinqaiser-afk/HBQ_AU_Projects/blob/Presentations/Material/(Group%201)%20Torrent%20Poisoning%20NS.pptx) | [PDF](https://github.com/haanibinqaiser-afk/HBQ_AU_Projects/blob/Presentations/Material/(Group%201)%20Torrent%20Poisoning%20NS.pdf)
* **Collaborators:** Haani Bin Qaiser, M. Asim Saleem, M. Abaid

### 3. Arrays of Objects in C++ 💻
* **Core Topics:** Object-Oriented Programming (OOP) concepts, syntax and memory architecture for declaring arrays of objects, default constructor behavior during instantiation, bulk data management, and transitioning to dynamic containers (`std::vector`).
* **Format:** [PPTX](https://github.com/haanibinqaiser-afk/HBQ_AU_Projects/blob/Presentations/Material/OOP%20Presentation%20247126.pptx) | [PDF](https://github.com/haanibinqaiser-afk/HBQ_AU_Projects/blob/Presentations/Material/OOP%20Presentation%20247126.pdf)
* **Collaborators:** Haani Bin Qaiser, M. Rizwan

### 4. Calculus & Analytical Geometry in Everyday Life and Cybersecurity 📐
* **Core Topics:** Practical applications of Differential and Integral calculus, coordinate system mapping via Analytical Geometry, modeling network server locations, and utilizing rate-of-change formulas to detect anomalous traffic spikes and network intrusions.
* **Format:** *PPTX (Not Available)* | [PDF](https://github.com/haanibinqaiser-afk/HBQ_AU_Projects/blob/Presentations/Material/Calculus%20Team%207%20PPT.pdf)
* **Collaborators:** Haani Bin Qaiser, M. Asim Saleem, M. Abaid, M. Rizwan, Nayab Farooq, Umaria Kanwal, Kshaf Asjad, Zakia Qayyum

### 5. Evolution of Wireless Communication: G in Mobile Networks 📱
* **Core Topics:** Historical shift from traditional distance communication (letter writing) to modern mobile networks, defining generations of cellular standards (1G through 5G), infrastructural demands, energy consumption profiles, and the outlook for 6G.
* **Format:** [PPTX](https://github.com/haanibinqaiser-afk/HBQ_AU_Projects/blob/Presentations/Material/ID_247126%20ICT%20Presentation.pptx) | [PDF](https://github.com/haanibinqaiser-afk/HBQ_AU_Projects/blob/Presentations/Material/ID_247126%20ICT%20Presentation.pdf)
* **Collaborators:** Haani Bin Qaiser, M. Asim Saleem, M. Abaid, Muhammad Hurraira

3. Open the file using **Microsoft PowerPoint** (version 2019 or later recommended for full Morph transition compatibility) and view it in Slide Show mode.

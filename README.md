# Academic & Technical Presentations 📊

Welcome to the **Presentations** branch of my portfolio. This repository contains a curated collection of presentations delivered during my undergraduate studies, covering topics across Cybersecurity, Computer Science, and Applied Mathematics.

## 📌 Note on Formats (`.pptx` vs `.pdf`)
Each presentation is provided in two formats:
* **`.pptx` (Recommended):** Download this version to experience the advanced **Morph transitions**, dynamic animations, and precise visual formatting that were built into the original slides.
* **`.pdf`:** A static version optimized for quick previewing directly inside GitHub or on devices without Microsoft PowerPoint.

* **Format:** `[PPTX Link]` | `[PDF Link]`

### 3. Arrays of Objects in C++ 💻
* **Core Topics:** Object-Oriented Programming (OOP) concepts, syntax and memory architecture for declaring arrays of objects, default constructor behavior during instantiation, bulk data management, and transitioning to dynamic containers (`std::vector`).

### 4. Calculus & Analytical Geometry in Everyday Life and Cybersecurity 📐
* **Core Topics:** Practical applications of Differential and Integral calculus, coordinate system mapping via Analytical Geometry, modeling network server locations, and utilizing rate-of-change formulas to detect anomalous traffic spikes and network intrusions.

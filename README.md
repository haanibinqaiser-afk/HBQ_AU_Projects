# Cryptography & Data Security

Welcome to the Cryptography module of my security portfolio. This space is dedicated to exploring fundamental and advanced cryptographic primitives, secure communication protocols, and implementation labs involving data encryption, hashing, and key management.

## 🚀 Learning & Project Roadmap

This branch is structured into distinct sub-modules tracking my hands-on labs and automated pipelines:

### 1. Classical & Historical Ciphers (`/classic-ciphers`)
Focuses on the roots of encryption, algorithmic logic, and constructing automated pipelines for historical algorithms.
* **Featured Lab:** *Automated Caesar Cipher CI/CD Pipeline* – Implementing a robust Caesar Cipher tool in C++, containerized via Docker, and fully automated using a Jenkins CI/CD pipeline to ensure code quality and secure build deployments.

### 2. Modern Symmetric Cryptography (`/symmetric-crypto`)
Focuses on high-speed data encryption using standard block and stream ciphers.
* **Upcoming Labs:** Hands-on policy testing, execution time analysis, and implementation of Advanced Encryption Standard (AES) configurations.

### 3. Asymmetric Cryptography & PKI (`/asymmetric-crypto`)
Exploring public-key infrastructure, digital signatures, and secure key exchanges.
* **Tools Focused:** OpenSSL configurations, RSA key pair generation, and implementation of secure TLS/SSL handshakes.

### 4. Data-at-Rest & Storage Security (`/storage-encryption`)
Practical implementations of file-system encryption and data protection policies.
* **Featured Lab:** *VeraCrypt Volume & Policy Testing* – Utilizing OpenSSL and VeraCrypt to configure encrypted volumes, test security policies, and evaluate resistance against unauthorized data extraction.
